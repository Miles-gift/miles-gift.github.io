# 首页与主导航规范

> 状态：阶段 4 基线
>
> 版本：v1.0
>
> 更新日期：2026-09-10

## 1. 目标

首页需要在首屏快速回答三个问题：这是 Miles 的个人数字花园；这里记录工程、学习与成长；访客可以继续阅读文章或查看当前关注。视觉借鉴发布会的舞台节奏，但只使用自有标识、真实文字、CSS 光影和内容数据。

## 2. 信息顺序

```text
Opening / 核心句与主视觉
├── Now / 当前三个关注方向
├── Featured Story / 精选文章
├── Learning Library / 三条资料
├── Thoughts / 三条短想法
├── Journey / 三个经历坐标
├── Latest / 三篇最新文章
└── Closing / About 与 RSS
```

顺序在移动端保持一致，不依赖轮播、悬停或动画才能理解内容。页面只有一个 `h1`，各章节使用 `h2`，卡片标题使用 `h3`。

## 3. 视觉决定

- 首屏使用大标题、宽留白、黑白灰和单一蓝紫渐变强调。
- 主视觉由 `miles-mark.svg`、CSS 圆环和光晕组成，不下载 Apple 或第三方发布会素材。
- 深色资料区作为叙事转场，其他章节沿用全站语义色与表面令牌。
- 首页卡片按内容职责区分：资料显示进度，短想法强调一句判断，Journey 强调时间坐标。
- 仅在允许动态效果时运行轻微漂浮和 AOS 滚动揭示；减少动态效果偏好会关闭动画。

## 4. 数据来源

- Opening 统计由公开 collections 数量实时计算。
- Featured Story 读取第一篇 `featured: true` 的文章。
- Learning Library 按 `lastReviewedAt` 选择三条资料。
- Thoughts 按发布时间倒序显示三条。
- Journey 显示教育起点、当前教育阶段和最新公开节点。
- Latest 按文章发布日期倒序显示三篇。

没有真实内容时应隐藏对应卡片或章节，不使用虚构占位数据。

## 5. 主导航

桌面和移动端固定为：首页、文章、资料库、旅程、关于。搜索和主题切换使用图标按钮；短想法、归档、RSS、隐私和源码放在页脚或辅助入口。

阶段 4 同时建立了四个可用的集合入口页，保证新导航不会指向空路由。阶段 5 会继续加入筛选、主题聚合、相关内容和更完整的发现能力。

## 6. 可访问性与性能

- 主视觉标记为装饰，不重复朗读品牌信息。
- 所有卡片使用完整可点击链接，移动触控目标不依赖微小图标。
- 移动菜单同步 `aria-expanded` / `aria-hidden`，支持 Esc、遮罩和关闭按钮，关闭后焦点回到触发器。
- 390px 视口无横向溢出。
- 首屏图像只有本地 112×112 SVG 标识，设置尺寸、`loading="eager"` 与 `fetchpriority="high"`，避免布局偏移。
- 继续使用系统展示字体；中文阅读字体仅在长文布局加载。

## 7. 阶段 4 验收

- 生产构建生成 30 个页面，首页、四个集合入口和五项主导航均存在。
- 桌面首屏层级、标题换行、视觉焦点与导航完成浏览器检查。
- 390×844 首屏、菜单、目标页和无水平溢出完成浏览器检查。
- 浏览器控制台 0 error / 0 warn。
- 正式 Lighthouse、断链和 SEO 全量门槛在阶段 7 统一执行；阶段 4 不引入新的远程字体、位图或第三方脚本。
