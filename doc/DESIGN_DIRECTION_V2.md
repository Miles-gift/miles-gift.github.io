# “流动手稿”视觉与信息架构

更新时间：2026-09-10

## 设计输入

- 站点名称：`yoyo的旅行日记`
- 气质：温暖、手工感、青春
- 主题：浅色与深色跟随系统，也允许访客手动切换
- 内容：长文、随心记、本人原始学习笔记、教育/获奖/校园经历与个人介绍
- 记忆点：首页以“知识轨迹”连接内容，不使用通用产品卡片瀑布流
- 动效：中等强度；一处首页编排动画，加上页面切换、搜索与直接交互反馈

## 第一版方向与自检

最初方案容易落入“米色纸张、衬线大标题、陶土色点缀”的常见个人博客模板，也容易继续用等尺寸圆角卡片分割所有内容。这两点都不能表达本站同时具有芯片研究、课堂笔记、生活经历和青春手记的真实混合感。

修订后的方向不模拟实体复古纸张，而把“手稿”解释为一条不断生长、可回看、会留下修订痕迹的线。界面用冷白和墨蓝保持工程信息的清楚，用莓红和嫩绿标记生活温度；大标题与引用使用文楷，正文使用宋体，操作界面保持简洁。圆角只用于必要的控件和手写便笺，不把每段内容装进相同卡片。

## 色彩令牌

### 浅色

| 名称 | 色值 | 用途 |
|---|---|---|
| 云纸 `paper` | `#F3F6F4` | 页面底色，冷白而不刺眼 |

| 墨蓝 `ink` | `#172B3A` | 正文与主结构 |

### 深色

| 名称 | 色值 | 用途 |
|---|---|---|
| 夜蓝 `paper` | `#10202A` | 页面底色，不使用纯黑 |
| 深纸 `sheet` | `#172B36` | 阅读与导航表面 |
| 月白 `ink` | `#EEF1E8` | 正文 |
| 湖蓝 `blue` | `#83B7D1` | 链接与轨迹 |

每个页面只让一个内容色成为主角；其余色彩只用来编码内容类型，不用作装饰渐变。

## 字体

- 展示标题与引用：`LXGW WenKai Bright`。笔画保留人的温度，只出现在短标题和引用中。
- 长文与学习笔记：优先使用系统宋体栈。正文行宽控制在 36–42 个中文字符，行高约 1.85；阶段 7 为降低完整中文字库体积，不再强制下载 Noto Serif SC。
- 导航、筛选与小尺寸信息：系统无衬线字体，保证辨认速度。
- 英文主题词与年份：`EB Garamond`，用于少量视觉节奏，不作为无意义的全大写 eyebrow。
- 代码：`JetBrains Mono Variable`。

## 动效与交互

- 首页知识轨迹在首次进入时完成一次描线；节点依次点亮，但内容从一开始就可见。
- 页面切换使用 Astro View Transitions 做短暂的纸页交叠，不显示旋转加载器。
- 搜索按钮展开为覆盖层，输入、结果更新和关闭有连续位置关系。
- 文章二级栏目切换使用 URL hash/query 保留状态，并使用 180–260ms 的内容交叉切换。
- 所有滚动只动画 `transform`、`opacity` 或 SVG stroke；不用高频逐帧监听。
- `prefers-reduced-motion: reduce` 下关闭轨迹绘制、位移和视差。

## 链接与公开边界

- 主导航只保留首页、文章、资料库、旅程、关于。
- 公开界面移除 Momo 上游、模板作者、源码、RSS、隐私、版权和旧 URL 入口。
- 必要的模板许可归属保留在仓库 LICENSE 与开发 README，不作为站点导航。
- 资料笔记可保留正文中原有且与学习内容直接相关的来源链接。
- 关于页保留 `Miles-gift` GitHub 与经本人确认的 `motues.top` 友联。
- 归档和搜索作为文章/导航中的辅助入口继续保留。

## 设计完成条件

- 3 秒内可判断站点是谁、记录什么、五个入口在哪里。
- 文章页可在不经过独立随想栏目导航的情况下切换长文与随心记。
- 资料库发布本人八份 Markdown 原文，正文不被自动总结。
- 教育、获奖、校园服务三个区块语义独立。
- 360、390、768、1024、1280、1440px 无水平溢出。
- 深浅主题、键盘焦点、搜索、移动菜单和 reduced motion 均可用。
