# Miles 前端设计方向

> 状态：阶段 5 起生效  
> 目标：在 Apple 发布会式的克制、清晰和舞台感之上，建立属于 Miles 的工程学习语境，而不是复刻某个品牌页面。

## 1. 设计立场

网站的主角是持续形成的知识，而不是界面组件。视觉语言取自工程学习中的“信号轨迹”：捕捉问题、动手验证、整理结果、公开发布、定期复盘。首页首屏的网格与折线是这一流程的唯一象征性主视觉，后续页面回到安静、易读的内容界面。

三个判断标准：

1. 一眼能看清信息层级，不依赖说明才能使用。
2. 每个视觉强调都能对应真实内容或操作，不用装饰性的编号、箭头和英文标签填充空间。
3. 动效帮助建立开场节奏或说明直接交互，不让所有卡片在滚动时轮流出现。

## 2. 视觉基线

### 色彩

| 角色 | 值 | 用途 |
| --- | --- | --- |
| 舞台黑 | `#000000` | 资料库等需要聚焦的深色章节 |
| 银白 | `#F5F5F7` | 浅色大背景与深色区文字 |
| 墨色 | `#1D1D1F` | 正文和高层级标题 |
| 信号蓝 | `#0071E3` / 现有主题近似值 | 链接、焦点、进度与主轨迹 |
| 校准紫 | `#7D5CFF` | 首屏轨迹终点，限量使用 |

浅色与深色模式都保持同一语义：蓝色代表可行动或正在发生，紫色只代表完成一次校准。正文区域不使用多彩渐变文字。

### 字体

- 展示与界面：系统无衬线栈，优先 SF Pro / PingFang SC，提供紧凑、精确的发布会节奏。
- 长文：`Noto Serif SC` 与系统宋体回退，建立阅读层与界面层的明显区别。
- 等宽字体：只用于代码和确有技术含义的数据，不用于普通日期、类型或装饰编号。

### 形状与空间

- 主要版心为 1180px 舞台宽度，长文为 760px 阅读宽度。
- 圆角用于可交互表面和明确容器；时间线、短想法列表优先使用线性分隔。
- 阴影只表达层级抬升，不与边框、渐变和发光同时堆叠。

## 3. 首页叙事

```text
┌─────────────────────────────────────────────┐
│ 主张与行动                 工程信号轨迹      │
│ 站点公开内容统计                             │
├─────────────────────────────────────────────┤
│ 此刻：工程实践 / AI 工具 / 长期整理          │
├─────────────────────────────────────────────┤
│ 重点长文：大幅视觉舞台 + 文章摘要             │
├─────────────────────────────────────────────┤
│ 深色资料库：状态、类型、进度                   │
├─────────────────────────────────────────────┤
│ 短想法（线性）→ 旅程（时间线）→ 最新文章      │
├─────────────────────────────────────────────┤
│ 慢慢积累，保持清醒                            │
└─────────────────────────────────────────────┘
```

首页保留一个编排好的入场：主张先出现，信号图随后出现，轨迹绘制一次。滚动章节不使用批量 `fade-up`；尊重 `prefers-reduced-motion`，关闭后仍可完整理解内容。

## 4. 内容页与发现页

- 文章、资料、短想法、旅程分别有自己的阅读结构，不强行套用同一种卡片。
- 聚合页标题直接说明内容，不重复放置 `Articles`、`Resources` 等英文眉题。
- 主题与标签页保留“按主题浏览 / 按标签浏览”，因为它能解释当前上下文。
- 资料筛选器必须显示命中数量；无结果时说明如何恢复。
- 搜索必须有加载、成功、空结果和索引不可用状态；用户查询只在本地索引中处理。
- 404 必须给出首页、搜索和文章三个明确出口。

## 5. 明确避免

- 标题中只挑一句做渐变或斜体的通用模板效果。
- 每个区块都放全大写英文眉题。
- 无信息含义的 `01 / 02 / 03` 装饰编号。
- 每个链接都附向右箭头，或所有内容都变成同款圆角卡片。
- 日期与普通元信息默认使用等宽字体或点号串联。
- 所有区块、卡片都在滚动时淡入；循环漂浮等不会结束的背景动效。
- 把未经本人确认的材料推断写成项目细节或个人贡献。

## 6. 验收清单

- 桌面和 390px 移动宽度无横向溢出。
- 页面只有一个主标题；键盘焦点可见；菜单、搜索与筛选无需鼠标即可使用。
- 首屏信号轨迹只播放一次，减少动态偏好下不播放。
- 浅色、深色主题的文字和操作保持可辨识。
- 长文中的标题、表格、代码、公式和插图不破坏阅读宽度。
- 空状态、失败状态都说明发生了什么以及下一步能做什么。
