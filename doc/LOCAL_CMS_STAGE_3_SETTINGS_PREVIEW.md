# 本地博客 CMS 阶段 3：博客设置与 Astro 预览

## 阶段交付

- 新增 `src/data/blog-settings.json` 作为可编辑的博客展示设置来源。原模板值保持不变；空背景路径继续回退到原始主题图。
- 设置项包括站点名称与摘要、博客 Hero 标题/副标题/背景、归档标题/动态介绍、无文章时的介绍、文章列表空状态，以及文章默认 Hero 背景。
- `src/config/site.ts` 和 `src/config/hero.ts` 从设置文件读取站点元信息及 Hero；博客归档页继续使用 Astro 原模板布局，将 `{total}`、`{current}`、`{last}` 替换为分页计算结果。
- CMS 增加“博客设置”页和字段校验；标题、摘要、图片路径、动态占位符均有长度或安全限制。设置先保存在 `.local-cms/blog-settings.json`，不会更改公开设置源文件。
- 新增“预览博客页”和“预览文章”。CMS 把当前工作树复制到系统私有临时目录，排除 `.git`、`.local-cms`、构建缓存后叠加本机文章、设置和图片，运行真实 Astro 开发预览。预览使用站点实际字体、布局、代码高亮、数学公式、目录与文章组件；MDX 使用站点运行时编译。
- 预览服务器只绑定 `127.0.0.1`。CMS 停止时同步终止预览并删除隔离快照；重启时清除本应用遗留的失效快照。预览不会覆盖公开源文件，也不会进入 Git。
