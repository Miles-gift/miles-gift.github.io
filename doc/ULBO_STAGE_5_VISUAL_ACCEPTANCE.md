# 阶段 5：Ulbo 视觉与交互验收

## 与上游的代码对照

对冻结上游 `a2b499937642f509c7aa481e0e7409d3d399121e` 逐目录比较后：

- `src/components/`、`src/layouts/`、`src/styles/`、`src/scripts/`、`src/lib/`、`src/plugins/` 与上游完全一致。
- `src/pages/` 与上游完全一致；唯一新增目录是旧 `/articles/<slug>/` 静态跳转页。
- `src/content.config.ts`、`package.json`、`package-lock.json` 与上游完全一致。
- `src/config/` 只有 `site.ts`、`profile.ts`、`hero.ts` 按计划替换站点和作者文案。
- `public/` 的 Ulbo 模板资产与上游一致；新增资源仅是两篇文章正文引用的 SVG。
- `astro.config.mjs` 仅新增一条规则，把 `/articles/` 旧 URL 跳转页排除出 sitemap。

没有为适配个人内容重写组件、样式、排版、断点、动画或交互。差异均为作者文字/个人身份、两篇文章插图和 GitHub Pages/旧地址兼容。

## 浏览器页面对照

使用同一 Codex 浏览器查看冻结版本对应的 Ulbo 在线演示与本站本地预览。检查了首页 Hero、个人简介、文章归档、长文阅读区及 390/768/1440 px 视口；浅色和深色均检查。截图在本阶段浏览器检查中直接查看，没有加入仓库，以免把临时屏幕截图作为网站静态资源。

| 检查项 | 结果 |
| --- | --- |
| 首页 Hero | 森林图像、导航叠层、标题/副标题位置、遮罩、滚动提示与模板一致；只替换显示文案和作者名。 |
| 字体 | computed font-family 为上游原值：正文 Plus Jakarta Sans 回退栈，标题 Outfit 回退栈；浏览器字体状态为 loaded。中文字符沿用上游定义的系统中文字体回退。 |
| 颜色与主题 | 主题按钮可在 light/dark 间切换；文章卡片/背景随主题改变，切换后的主题状态可持续。 |
| 手机菜单 | 390 px 显示模板菜单按钮；展开后 Home、Blog、Tags、About 四个原版入口均可访问。 |
| 搜索 | 按钮打开搜索模态框；搜索“数字花园”返回两篇相关长文；`Meta+K` 打开、`Escape` 关闭。 |
| 长文详情 | Hero、日期、阅读字数/时间、PDF 控件、正文卡片和桌面目录均按模板显示；作者图片和段落正常。 |
| 图片灯箱 | 点击文章插图打开 Ulbo 灯箱，按 Escape 关闭。 |
| 页面导航 | 页面头部具有上游 `ClientRouter` 与启用标记；路由导航使用模板控制器和 fallback 设置。当前嵌入浏览器不提供原生 `document.startViewTransition` API，故由模板自身 fallback 路径处理。 |
| 响应式溢出 | 在 390 px 与 768 px 视口检查 `documentElement.scrollWidth === clientWidth`；未见横向溢出。1440 px 桌面长文显示宽版 Hero、阅读卡与侧边目录。 |
| 减少动态效果 | 全局样式、搜索弹窗与目录脚本都保留上游 `prefers-reduced-motion` 处理。 |

## 素材和许可

- Ulbo 仓库包含 MIT `LICENSE`，该文件随上游完整保留；森林背景作为上游模板项目资产原样使用。上游没有为该单张图片提供独立素材出处说明，本次依据模板仓库随附许可保留原文件，没有另外换图或重绘。
- 原站文章插图为作者仓库里的 SVG，逐字迁入。
- 上游示例头像不用于作者资料；作者未提供公开头像，因此由原版 About 组件显示首字母占位。
- 四篇文章原有 CC BY-NC-SA 4.0 记录见 `doc/CONTENT_LICENSES.md`，与 Ulbo 代码 MIT 许可分开登记。
