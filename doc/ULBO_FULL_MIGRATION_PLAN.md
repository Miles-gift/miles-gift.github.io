# Ulbo 前端完整迁移执行计划

> 创建日期：2026-09-26  
> 执行分支：`codex/ulbo-full-migration`  
> 目标站点：`https://miles-gift.github.io/`  
> 视觉基准：[Astro 主题页](https://astro.build/themes/details/ulbo/) · [演示站](https://template.ulna520.top/) · [上游源码](https://github.com/xxy1103/ulbo-astro-theme-template)，核对提交 `a2b4999`

## 1. 目标和边界

此次工作以 Ulbo 的**实际前端结构**为基准重建界面：全屏图片 Hero、覆盖在图像上的透明导航、下方浅色背景与悬浮内容卡、文章列表、带大图的内页头部、长文阅读区和对应的明暗主题。上一轮改版留下的纯文字首屏、四格编号导航、全站细线列表、笔记纸张装饰和常驻白色导航，不再作为视觉骨架。

现有 37 条公开内容仍属于作者本人；文章、资料、短想法、旅程四个 Collection 及其 Frontmatter 保持有效。迁移的是**呈现和导航**，不是把资料和旅程硬改写为博客文章。既有公开 URL、CMS 创建和预检流程、Pagefind 索引、SEO 字段与 GitHub Pages 发布流程必须继续工作。

## 2. 参考设计拆解与校准

### 2.1 模板可复核特征

| 区域 | Ulbo 上游做法 | 本站迁移方式 |
| --- | --- | --- |
| 首屏 | 视口高度的森林照片、暗色遮罩、居中标题与副标题、向下提示 | 使用有许可的上游默认照片，标题改为本站真实简介；首页保留 100dvh，高度与窄屏兜底与模板一致 |
| 导航 | 64px 固定导航；首页叠在 Hero 上；滚动后转为表面色；菜单下划提示 | 改写现有 Header，使首页和其他 Hero 上透明，滚动后可读；保留中文栏目和现有搜索/主题入口 |
| 内容过渡 | Hero 后由浅灰背景承接白色圆角卡片，卡片有轻阴影 | 首页、栏目、详情均采用共享浮层容器；避免原版的裸露横线分区 |
| 首页内容 | 站点统计及最近发布文章 | 统计内容按四类现有资料生成，不虚构数据；最近更新按真实发布时间跨类型聚合 |
| 列表与归档 | 文章标题、摘录、日期、标签的可扫描列表；悬停左侧强调色 | 文章、资料、想法和旅程按内容特性分别映射到统一列表样式 |
| 阅读页 | 大图标题区、阅读元信息、正文卡片和目录 | 沿用现有 Markdown、公式、灯箱；替换外观并保留 URL、标题层级与移动目录 |
| 搜索和发现 | 浮层搜索、标签探索、归档 | 保留已验证的 Pagefind 与现有筛选逻辑，只统一外观和焦点状态 |

### 2.2 设计令牌第一稿

| 名称 | 色值 | 用途 |
| --- | --- | --- |
| 画布 | `#f4f5f6` | Hero 下方的页面背景 |
| 内容表面 | `#ffffff` | 浮动卡和内容容器 |
| 主文字 | `#333333` | 标题与正文 |
| 次文字 | `#666666` | 简介、时间与辅助信息 |
| 重点蓝 | `#2337ff` | 可操作链接、焦点、当前栏目 |
| 深色画布 | `#0f1117` | 深色主题背景 |

字体采用 Ulbo 的 Outfit 标题和 Plus Jakarta Sans 界面文字，中文回退到本站已自托管的霞鹜文楷；长文阅读使用现有宋体栈。内容宽度：Hero 覆盖视口；浮动卡最大 1200px；正文主列保持适合中文阅读的 720–800px；目录在空间允许时置于旁侧。

### 2.3 布局草图与自我校准

```text
桌面首页                          手机首页
┌──────────────────────────────┐  ┌──────────────┐
│品牌       栏目       搜索/主题 │  │品牌      菜单│
│                              │  │              │
│      摄影背景 + 一句话标题     │  │   摄影背景   │
│          副标题              │  │   标题/简介  │
│           ↓                  │  │      ↓       │
├──────────────────────────────┤  ├──────────────┤
│   白色浮动卡：真实内容统计     │  │ 白色内容卡   │
│   最新内容列表                │  │ 最新内容列表 │
│   四类内容入口                │  │ 分类入口     │
└──────────────────────────────┘  └──────────────┘
```

第一稿检查：旧版的编号四格和全大写 eyebrow 属于通用模板化装饰，且与 Ulbo 实际页面不符，移除。上游森林照片能准确传达“旅行日记”的沿途与探索，但不能让照片吞没内容：唯一强视觉投入放在首屏大图，正文区域用克制的白色卡片和有信息意义的日期/分类。首页标题采用作者既有表达，栏目文案指向真实内容，不生成空泛标语。动效限于导航状态和用户操作；尊重 `prefers-reduced-motion`。

## 3. 内容和路由映射

迁移基线（2026-09-26）：文章 4 篇、资料 9 条、想法 3 条、旅程 21 条，共 37 条且均公开；`CI=true pnpm quality` 通过，生产构建生成 103 个 HTML、3,158 个内部链接，Pagefind 索引 38 页 / 3,907 词。上游参考仓库是 MIT 许可；仓库没有说明默认森林照片的独立来源，本次不直接复制该照片，另制可用的本站 Hero 资源。

| 现有来源 | 新页面位置 | 公开地址要求 | 特殊元信息 |
| --- | --- | --- | --- |
| `articles` | 首页最近更新、文章列表、文章详情、主题/标签/归档 | `/articles/` 与 `/articles/<slug>/` 继续有效 | 主题、日期、描述、标签、封面、canonical |
| `resources` | 资料列表、资料详情、主题/标签与首页入口 | `/resources/` 与详情地址继续有效 | 资料类型、复核时间、来源和状态 |
| `thoughts` | 首页最近更新、文章页短想法区、想法详情 | `/thoughts/<slug>/` 继续有效 | 发布时间、主题、关联内容 |
| `journey` | 旅程列表、详情、首页入口 | `/journey/` 与详情地址继续有效 | 时间范围、机构、角色、类型 |
| `spec/about` | 个人介绍页 | `/about/` 继续有效 | 不编造头像和履历 |
| 旧地址 | 静态迁移页 | `/blog/<slug>/`、`/archive/` 继续到新地址 | `noindex`、canonical 与跳转目标 |

四类集合继续由 `getPublicEntries` 统一筛除 draft、unlisted；首页和搜索不得越过该规则。迁移前后记录数量、所有页面生成数与站内链接，任何减少都必须解释。

## 4. 分阶段实施

### 阶段 0：基线与参考冻结

1. 记录当前分支、质量命令、内容数量、公开路由、搜索索引与构建页面数。
2. 阅读 Ulbo 实际首页、导航、Hero、卡片、列表、文章布局以及全局令牌；记录参考提交，避免只凭主题页文字猜测外观。
3. 核对上游图片许可或改用本站自有图片，更新归属文档；保留已有字体许可证。
4. 建立页面对照表和响应式断点检查清单。

**完成标准**：计划、参考证据、内容/路由基线可复核；工作区干净；阶段提交推送远端。

### 阶段 1：替换全站外壳与设计令牌

1. 建立共享摄影 Hero 和悬浮内容卡组件，分别支持首页全屏、栏目和详情紧凑版。
2. 重写 Header：透明状态、滚动后实体状态、中文导航、搜索、明暗主题和移动抽屉；保证键盘/焦点与 Escape。
3. 重写 Footer、全局背景、字体、颜色和容器；处理浅色/深色主题首次绘制。
4. 去掉旧版首屏所依赖的 stage-shell、细线栏目视觉，保留必要的兼容令牌供未迁移页面暂用。
5. 检查 390px、768px、1440px 的导航高度、按钮触达和 Hero 文案遮罩对比度。

**完成标准**：所有页面共享新的 Ulbo 外壳；`CI=true pnpm quality` 通过；阶段提交推送远端。

### 阶段 2：首页和跨类型内容入口

1. 首页呈现 Ulbo 式 100dvh 摄影 Hero、真实简介、向下提示。
2. Hero 下为浮动白卡：真实内容统计、跨四类的最近更新，以及清晰的各类入口；不使用编号四格。
3. 从现有内容读取标题、摘要、日期、主题，保持精选文章与最近更新可直接打开。
4. 根据实际发布日期排序，空列表提供有用提示；手机端按一列组织信息。

**完成标准**：首页具有与 Ulbo 演示站明显一致的首屏和卡片结构；内容链接均指向真实项目；阶段质量检查和推送完成。

### 阶段 3：栏目、标签、归档、搜索页

1. 文章、资料、旅程、标签、主题、归档、搜索、关于统一使用紧凑摄影 Hero 和浮动主卡。
2. 改造卡片/列表为 Ulbo 的标题、摘录、元信息层级；资料状态和旅程时间保留特殊呈现。
3. 保留现有筛选查询参数、Pagefind、标签/主题筛选和归档锚点；筛选后的空状态应解释如何清除条件。
4. 复核分页、404、旧地址迁移页的视觉协调，迁移页保持清晰的目的地址。

**完成标准**：每类列表与发现页可用，键盘可打开和重置筛选；构建输出路由数量不下降；阶段推送完成。

### 阶段 4：四类详情与长文阅读

1. 文章、资料、想法、旅程详情改用摄影 Hero，标题和阅读信息置于图上，正文以浮动卡承接。
2. 保留现有 Markdown、代码、公式、灯箱、外链标识和锚点；清理旧版“资料笔记纸”装饰与旧详情标题区。
3. 目录在桌面固定于正文旁边，在手机上通过已有按钮展开；提供明确当前章节与可见焦点。
4. 检查无封面、超长标题、表格、长代码块与小屏窄列。

**完成标准**：四类详情真实内容完整、URL/SEO 不变、目录可操作；阶段质量检查和推送完成。

### 阶段 5：内容工作流、SEO 与素材治理

1. 保持四个 Astro Collection 和 CMS 字段一致，跑 CMS 创建/预检/保存/图片冒烟测试。
2. 检查 sitemap、robots、canonical、OG、结构化数据、旧路由与搜索索引；草稿和非公开内容必须排除。
3. 记录直接借用的 Ulbo CSS/组件/摄影素材及 MIT 许可，保留字体 OFL 文本。
4. 删除已无调用的旧版外观组件与过时 CSS，避免新旧样式同时作用。

**完成标准**：`CI=true pnpm quality`、CMS build/smoke、公开构建检查通过；许可记录准确；阶段推送完成。

### 阶段 6：视觉与交互验收、上线

1. 对首页、列表、详情、搜索、关于和 404，在 390px、768px、1440px 分别核对浅/深色布局、图片裁切、溢出和触控操作。
2. 实际用键盘走通导航、搜索、主题切换、移动菜单、目录、筛选与返回路径；核对减少动态效果。
3. 对照 Ulbo 演示站检查：全屏摄影 Hero、透明导航、浅灰承接区、白色卡片、列表与阅读布局均已落地。
4. 整理验收记录及未能完成的设备检查，运行完整质量命令；按之前的发布要求，阶段提交推送，合并 `main` 并确认 GitHub Pages 发布。

**完成标准**：自动化检查通过，所有可操作设备检查有结果，核心路由有效，线上页面展现新的 Hero 与内容布局。

## 5. 执行顺序与回退

每阶段先做修改，再运行相应的类型检查、内容检查、构建与路由检查；通过后单独提交并推送。若某阶段失败，保留最后一个通过检查的提交，不把失败提交合入 `main`。发布前比较 `main` 与迁移分支，确认没有新内容被覆盖。若最终浏览器设备不可操作，自动化验收继续进行，并把视觉/交互检查明确标为待复核，不能写成通过。
