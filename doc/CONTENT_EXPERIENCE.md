# 阶段 5：内容页面与发现体验

> 状态：已完成  
> 版本：v1.0  
> 更新日期：2026-09-10

## 1. 目标

阶段 5 把阶段 3 的内容模型和阶段 4 的首页入口连接成完整阅读路径。访客可以从首页进入列表，在文章、资料、短想法、经历和固定页面之间继续探索；筛选、搜索、空结果与旧 URL 都有明确行为。

## 3. 筛选约定

文章筛选参数：

- `q`：标题、摘要、主题或标签关键词。
- `topic`：受控主题。
- `tag`：单一标签。
- `year`：发布日期年份。

资料筛选参数：

- `q`：标题、摘要或标签关键词。
- `topic`：受控主题。
- `type`：资料类型。
- `status`：学习状态。

筛选直接作用于构建时输出的卡片，不向第三方发送查询。每次变化都会同步当前 URL，刷新、前进后退和复制链接后可以恢复；结果计数通过 live region 宣告。零结果时显示恢复建议，重置按钮回到完整列表。

## 4. 长文阅读样例

《内容不是文件：把个人知识库变成可持续发布系统》作为阶段 5 的真实长文样例，超过 3000 个中文字，并覆盖：

- 二至三级标题与目录数据。
- 自有 `content-loop.svg` 内容循环与 `publication-boundary.svg` 发布边界插图。
- Markdown 表格。
- 两处代码块。
- KaTeX 行内与块级公式。
- 引用、提示内容、内部链接与相关推荐。

样例不是占位 lorem ipsum，而是复盘本项目从素材到公开页面的真实内容循环。

## 5. 设计与交互约束

- 文章、资料、想法和旅程使用不同信息结构，不把全部内容压成同款卡片。
- 删除无语义的英文眉题、装饰编号和普遍存在的向右箭头。
- 首页采用工程“信号轨迹”主视觉；只运行一次开场编排，不对每张卡片应用滚动淡入。
- 列表和详情都只有一个 `h1`，时间线与短想法保持线性阅读。
- 搜索弹窗使用 dialog 语义、焦点锁定、Esc 关闭和焦点返回；独立搜索页负责可分享查询。
- 外部资料始终跳转原始来源，不在仓库镜像无授权文件。

完整视觉决定见 [FRONTEND_DESIGN_DIRECTION.md](FRONTEND_DESIGN_DIRECTION.md)。

## 6. URL 兼容

- 规范文章 URL 为 `/articles/<slug>/`。
- `/blog/<slug>/` 保留 `noindex` 迁移页，声明新 URL 为 canonical。
- 历史单数路径 `/archive/` 迁移到 `/archives/`，不进入索引。

GitHub Pages 无服务器级 301，因此当前使用静态 canonical + meta refresh + JavaScript 跳转。未来接入边缘层后再转换为真正的永久重定向。
