## 1. 文档目的

本简报将“想要一个可以发布学习资料、个人信息、思考与经历的博客”转化为可执行的品牌与内容决策。它回答四个问题：

1. 这是谁的网站，给访客什么样的第一印象？
2. 网站会长期写什么，不写什么？
3. 首发需要准备哪些真实内容？
4. 当个人资料尚未提供时，哪些默认值可以安全使用？

本阶段不编造履历、职业、学历、城市、年龄、专业身份或私人联系方式。未经证实的个人信息保持空缺，不使用占位故事掩盖。

## 3. 品牌核心

### 3.1 品牌角色

Miles 个人站是一份“正在生长的公开档案”。它首先服务于长期记录和检索，其次才是对外展示。

它应该给人以以下感受：

- 安静：不使用刺眼的促销语气或过度动效。
- 清晰：快速回答“这是什么、这里有什么”。
- 真实：清楚区分事实、意见、未完成想法和修订。
- 克制：少而有意义的强调，让内容占据中心。
- 有时间感：保留学习、决策和观点如何变化的轨迹。

### 3.2 一句话定位

> 一份关于学习、思考、作品与经历的长期公开记录。

### 3.3 核心价值

1. **积累**：让一次性阅读变成可检索、可修订的长期资产。
2. **连接**：将分散的笔记、项目、资料与人生阶段建立关联。
3. **反思**：保留不确定、失败、修正和认识变化。
4. **分享**：将已经理清的内容提供给有相似问题的访客。

### 3.4 标语使用层级

- Hero 主句：持续学习，也持续留下些什么。
- Hero 解释：从电子设计、AI 到语言学习，记录正在发生的成长。
- 站点描述：Miles 的工程实践、学习笔记与成长记录。
- About 定义：从工程实践到持续学习的公开档案。

## 4. 语气与写作规范

### 4.1 语气

- 使用第一人称，不用“我们”伪装个人站为团队。
- 直接说明问题、做法和限制，减少空泛的宣言。
- 允许使用“目前”、“我还不确定”、“这个结论已修订”。
- 专业词只在有助于准确表达时使用，首次出现时给出简短解释。
- 资料整理中明确标记原文、摘要、个人笔记和推断的边界。

### 4.2 应避免

- 未经证实的职业、成就、教育或项目数据。
- “颠覆”、“极致”、“震撼”等无事实支撑的宣传词。
- 只有氛围、没有信息的长句。
- 把他人的文章、课件或图片当作自有内容。
- 把还在变化的观点写成永久真理。

### 4.3 建议文章结构

1. 先用一段话说明结论或问题。
2. 交代语境、条件和目标。
3. 记录做法、关键证据与取舍。
4. 说明不适用范围、遗留问题或可能修订的部分。
5. 需要时附参考来源和更新日期。

## 5. 视觉身份基线

### 5.1 代表性标识

首发前使用 `public/brand/miles-mark.svg` 作为站点标识和 favicon。

结构：

- 圆角正方形深色底面，保证在浅色和深色环境中都能识别。
- 单线条字母 M，对应 Miles。
- 白到蓝的轻微渐变，作为未来单一强调色的起点。
- 不使用 Apple 商标、产品轮廓或发布会官方素材。

限制：这是设计系统建立前的临时品牌基线，阶段 2 需要在 16、32、64、128 像素下检查可辨识性，并决定是否保留渐变。

### 5.2 与 Apple 发布会风格的关系

借鉴的是信息表达方法：单一焦点、大标题、充足留白、分章叙事、深浅场景切换和节制动效。不借鉴 Apple 的商标、产品造型、官方摄影、文案或页面的逐像素布局。

## 9. 信息公开分级

### 9.1 Public：可以进入网站

- 经确认的昵称 Miles。
- 公开 GitHub 主页和公开项目。
- 本人原创、已复核的文章与笔记。
- 已获授权的照片、截图和引用。
- 经模糊化且不造成安全风险的经历与时间线。

### 9.2 Draft：可以进入私有工作流，不可生成公开页面

- 尚未核对的数据、引用和结论。
- 尚未得到他人授权的故事、照片或对话。
- 含有私密信息、尚未完成脱敏的内容。
- 可能对当事人造成现实影响的即时情绪记录。

### 9.3 Private：不得进入公开仓库

- 密码、API 密钥、访问令牌、身份证件和金融信息。
- 家庭住址、实时位置、日常行程和其他可用于定位的信息。
- 未经同意的他人联系方式、医疗、财务、工作或关系信息。
- 只希望自己保留、不愿意被长期索引的日记。

## 10. 发布前个人内容检查

每次发布与个人经历有关的内容前，至少确认：

- [ ] 时间、地点、数据和链接已核对。
- [ ] 个人事实与个人观点有明确区分。
- [ ] 他人姓名、照片、引语和对话已得到同意，或已完成必要脱敏。
- [ ] 截图中没有用户名、邮箱、通知、定位、令牌或浏览器个人信息。
- [ ] 所有非原创材料已标记作者、来源和许可范围。
- [ ] 内容即使在搜索引擎中长期存在，仍然可以接受。
