# 本地博客 CMS 阶段 2：文章编辑与本机工作区

## 阶段交付

- 完成 Markdown 与 MDX frontmatter 解析、校验和序列化；文章正文按原内容保留，日期输入按 `Asia/Shanghai` 转换，标题、摘要、更新时间、分类、标签、草稿状态和封面均可编辑。
- 新文章、复制文章、编辑已发布文章、保存本机修改、删除本机新稿、标记已发布文章待删除及恢复均在 CMS 中完成。已发布文件仍保持不变，CMS 把编辑版本、源文件哈希、基线 Git SHA 和基线正文保存到被 Git 忽略的 `.local-cms/drafts/`。
- 正式文章沿用网站现有分类和标签约束；空分类/标签使用 YAML 空数组，允许不完整的私有草稿。标签会去重并沿用现有英文小写与空格规范；分类和标签控件提供现有值建议。
- 新增可选 `cover` 字段，只接受 `/uploads/blog/` 下的站内路径；frontmatter 检查脚本会保留该字段。文章页面的 Hero、Open Graph/Twitter 分享图片和 JSON-LD 结构化数据采用封面图，并在未设置封面时回退至原有模板背景图。
- 图片上传仅接收 PNG、JPEG、WebP，限制 20 MB 与 4000 万像素，使用 Sharp 输出不超过 2400×2400 的 WebP，并只保存在私有 `.local-cms/media/`。编辑器可将它设置为封面或插入正文 Markdown 图片引用。
- 编辑器提供正文对比、标题/粗体/链接/代码/列表快捷插入、未保存离开提示和字数提示。源码按纯文本显示，避免把文章内容当 HTML 执行。
- 本阶段尚不发布：工作区变更不会写进公开文章目录，不提交 Git，也不影响线上页面。将图片复制到公开目录和发布前构建检查归入后续发布流水线阶段。
