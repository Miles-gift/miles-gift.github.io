## 记录原则

1. 尽量写清事实、时间和信息来源。
2. 把过程、失败和修正一起留下，而不只展示结果。
3. 让长文、资料和短想法各有合适的位置。
4. 不为了填满页面而虚构经历或观点。

## 关于本站

本站基于 Astro、Markdown、Pagefind 与 Momo 开源模板重建，内容保存在 Git 中，经本地检查后由 GitHub Actions 自动发布到 GitHub Pages。正文与网站代码的许可边界分别写在[版权与转载说明](/copyright/)；收集信息、第三方服务和公开边界写在[隐私说明](/privacy/)。

本站只发布适合公开、且经过复核的内容。身份证件、精确住址、账户密钥、未经同意的他人信息，以及不适合长期公开的私密记录，都不会进入公开仓库。
