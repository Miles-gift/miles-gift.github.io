## 为什么收藏

本地 Git 文件目前只有标题，无法作为有效资料。与其补一份孤立命令表，不如从官方电子书建立“工作区、暂存区、提交、引用和远端”之间的联系。

## 学习重点

先覆盖日常提交、分支、合并与远端协作，再学习检查历史、定位问题和安全恢复。涉及删除或重写历史的命令只在临时仓库练习，不把高风险操作写成无上下文的速查。
