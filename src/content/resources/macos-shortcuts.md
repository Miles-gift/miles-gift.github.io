# Macbook快捷键

## 一、fn

|    按键     |     效果     |
| :---------: | :----------: |
|    Fn+F     |     全屏     |
| Fn + delete | 删除后面内容 |
|   Fn + Q    |  新建备忘录  |
|   Fn + N    | 打开通知中心 |
|   Fn + C    | 打开控制中心 |

## 二、control

|         按键          |         效果         |
| :-------------------: | :------------------: |
|     control + 上      |     打开调度中心     |
|     control + 下      |     平铺所有窗口     |
|    control + 左/右    |       切换桌面       |
|      control + K      | 一键删除光标后的内容 |
| control + command + D |         翻译         |
